Descripción del proyecto

WorldExplorer es una aplicación web que permite explorar información detallada de los 195 países del mundo. Los usuarios pueden buscar países por nombre, filtrar por región y ver detalles como capital, población, idiomas, moneda y ubicación en el mapa.

Tecnologías utilizadas

Angular 21
HTML5
CSS3
TypeScript

API utilizada

REST API

REST Countries

Proporciona datos del mundo en tiempo real: nombre, capital, región, subregión, población, área, banderas, idiomas, monedas, zonas horarias y más.

Endpoint: https://api.restcountries.com/countries/v5
